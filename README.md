🌱 Carbon Footprint Coach

An interactive web application that helps users estimate their carbon footprint and explore practical ways to reduce their environmental impact.

🎯 Project Overview

Carbon Footprint Coach is a software-based sustainability project designed to promote environmental awareness. Users can enter their daily travel, electricity consumption, and meat-based meal information to estimate their carbon emissions and explore potential reduction scenarios.

✨ Features

- 🌍 Carbon footprint estimation
- 🚗 Transport emission calculation
- ⚡ Home electricity emission calculation
- 🍽️ Food-related emission estimation
- 📊 Interactive carbon emissions breakdown chart
- 🌿 Personalized rule-based eco-friendly recommendations
- 🎯 Carbon reduction scenario simulator
- 💾 SQLite database for assessment history
- 📱 Responsive web interface

🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- SQLite
- Chart.js

⚙️ How to Run the Project

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

Replace "YOUR_GITHUB_REPOSITORY_URL" with your repository's actual URL.

2. Open the project folder

cd carbon-footprint-coach

3. Install dependencies

python -m pip install -r requirements.txt

4. Run the application

python app.py

5. Open in your browser

Visit:

"http://127.0.0.1:5000"

📊 How It Works

1. Enter your transportation method and travel distance.
2. Enter your electricity consumption.
3. Enter your meat-based meal count.
4. Calculate your estimated carbon footprint.
5. View the emissions chart and potential reduction scenario.
6. Explore recommendations for more sustainable habits.

⚠️ Disclaimer

This project uses simplified illustrative emission factors for educational purposes. The estimates are not an official carbon inventory and should not be treated as verified measurements.
